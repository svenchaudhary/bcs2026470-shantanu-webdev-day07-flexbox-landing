## Project Description

Fieldnotes is a responsive outdoor-gear landing page
created as part of the Day 7 / Week 7 Flexbox assignment.

The website is designed for an outdoor equipment brand.
It provides a clean and modern interface with product
images, membership plans and a login form.

The project demonstrates the practical use of CSS Flexbox
to create responsive layouts for desktop, tablet and
mobile devices.

## Flexbox Concepts Used

### 1. Display Flex

Used to arrange elements horizontally and vertically.

### 2. Justify Content

Used to distribute space between elements.

### 3. Align Items

Used to align items along the cross axis.

### 4. Flex Wrap

Allows product and pricing cards to move to new rows
when screen width becomes smaller.

### 5. Flex Grow and Flex Basis

Used to make product cards adjust their sizes
according to available space.
